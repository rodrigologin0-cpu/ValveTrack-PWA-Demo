# ValveTrack PWA Demo

Demonstração técnica pública para validação da PWA. **Somente dados fictícios.**

- 80 cartões em cada uma das duas unidades fictícias; 40 por lado.
- Posições manuais, fotos de teste e histórico armazenados localmente no navegador.
- Não há conexão com SharePoint, Microsoft Graph ou outros serviços de sincronização.
- Não usar dados reais, imagens industriais ou nomes pessoais.

## GitHub Pages

Settings → Pages → Build and deployment: Deploy from a branch → main / (root) → Save.
